# React Native - Native Module for Couchbase Lite Enterprise

This repository contained the legacy **`cbl-reactnative`** React Native native module for Couchbase Lite Enterprise (legacy React Native architecture). It has been superseded by the officially supported scoped package **`@couchbase/couchbase-lite-react-native`**.

Shared TypeScript and native bridge code in git **submodules** (for example `cblite-js`, `cbl-js-swift`, `cbl-js-kotlin`) remains in use by other projects and is **not** deprecated.
